# 🍟 推しポテトメーカー

推しの画像をフライドポテトの容器に入れて遊べる、ブラウザ完結のジェネレーターです。

## 特徴

- 📷 推しの画像をアップロード（PNG / JPEG / WebP、透過PNG対応）
- 🍟 最初から容器にこんもりポテト。推しが上から降ってきて、手前にもポテトが降る演出
- ▶️ 再生ボタンで演出を繰り返し楽しめる
- 🤏 推しをタップ／長押しすると持ち上がる
- 🍟 ポテトを1本ずつつまんで取り出せる（最大64本）
- 📏 推しのサイズ調整・位置調整（いどうモード）
- 🔄 ワンタップでリセット
- 📱 操作バーは常に1画面内に収まる（スクロール不要）
- 🔒 画像はすべて端末内で処理。外部サーバーへの送信・保存なし

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ本体・操作UI・オーバーレイ |
| `style.css` | デザイン（赤・黄・クリーム基調） |
| `app.js` | Canvas描画・落下アニメ・タップ判定などの全ロジック |
| `tests/test.js` | 純粋ロジック（ジオメトリ・着地位置）のユニットテスト |

サーバー・データベース・外部ライブラリは不要です。

## ローカルで開く

ファイルをそのままブラウザで開いても動きます。
ファイル選択機能が安定するローカルサーバー起動の例:

```bash
cd oshi-potato
python3 -m http.server 8080
# http://localhost:8080 を開く
```

## GitHub Pages で公開する

1. このフォルダをリポジトリにプッシュする
2. リポジトリの Settings → Pages でソースを `main` ブランチの `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## テストの実行

```bash
node tests/test.js
```

着地位置の範囲・重複回避・容器のはみ出し防止などを300サンプルで検証します。

## 遊び方

1. 「📷 推しをえらぶ」で画像をアップロード
2. ポテトが自動で降ってきます（満タンで停止）
3. 推しやポテトをタップ／長押ししてつまむ
4. 「🍟 ポテトついか」で追加、「📐 いどうモード」で位置調整
